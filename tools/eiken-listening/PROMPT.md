# 英検リスニング教材 生成プロンプト（手動運用版）

ChatGPT / Claude などにそのまま貼り付けて使うプロンプトです。
`{{DATE}}` を当日の日付に置き換えてください（自動化する場合は `gas/Code.gs` が
自動で差し替えます）。

ウェブ検索が使えるモデル（ChatGPT の検索オン、Claude の web search など）で
実行してください。検索が使えない場合は、先にニュース記事を数本貼り付けてから
このプロンプトを続けて送ってください。

既定は **英検準1級のみ**です。2級・3級も欲しい日は「■ 2」のレベル定義に
該当ブロックを足してください（コメントで書き足し方を示しています）。

---

## ▼ ここからコピー ▼

```
あなたは英検対策教材の英文ライター兼ニュースエディターです。
本日（{{DATE}} 日本時間）のニュースをもとに、リスニング（シャドーイング・
ディクテーション）用の英文スクリプトを作成してください。
作成した英文は、私が音声読み上げAIに読ませて聞き取り練習に使います。

━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 1. ニュースの選定
━━━━━━━━━━━━━━━━━━━━━━━━━━
・世界のニュースを2本、日本のニュースを2本、合計4本選ぶ
・直近48時間以内に報じられたものに限る
・分野が偏らないようにする（政治／経済・ビジネス／科学技術／社会・環境
  からなるべく散らす）
・事件事故の生々しい描写、センセーショナルな話題は避け、
  朝に聞いて前向きに学習できる題材を優先する
・数値・固有名詞・日付は報道どおり正確に書く。裏が取れない数字は書かない
・各ニュースの出典媒体名を、最後の日本語パートに列挙する
・推測や創作を混ぜない。事実が足りない部分は書かずに省く

━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 2. レベル
━━━━━━━━━━━━━━━━━━━━━━━━━━
【英検準1級 / CEFR B2】
  語彙  : 準1級頻出の抽象語・アカデミック語を1パートあたり5〜8語は入れる
          （例: unprecedented, allocate, mitigate, subsequently, deterioration）
  文長  : 平均18〜25語
  文法  : 分詞構文、関係副詞、仮定法、無生物主語、話法の転換を自然に使う
  総語数: 1300〜1500語（読み上げ約10分 / 150wpm）

  ※2級も欲しい日は、同じ4本のニュースを次の条件でもう一式書く:
  【英検2級 / CEFR B1】
    語彙 高校標準レベル / 文長 平均12〜18語 /
    文法 現在完了・受動態・関係代名詞・不定詞・接続詞による複文まで /
    総語数 900〜1100語 / 130wpm

  ※3級も欲しい日は、さらに次の条件でもう一式書く:
  【英検3級 / CEFR A2】
    語彙 中学卒業レベル（難語は必ず平易な語に置き換える）/
    文長 平均8〜12語・1文1情報 /
    文法 中学英語の範囲＋現在完了（分詞構文・関係副詞は使わない）/
    総語数 500〜650語 / 110wpm

  複数レベルを書く場合、レベル間で事実関係に食い違いが出ないようにする。
  要約の長短ではなく、語彙・文構造そのものをレベルに合わせて作り直すこと。

━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 3. 音声読み上げ用の書式ルール（最重要）
━━━━━━━━━━━━━━━━━━━━━━━━━━
本文は音声読み上げAIにそのまま渡すため、次を厳守すること。

・本文に記号・絵文字・Markdown記法（*, #, -, > など）を使わない
・箇条書きにしない。必ず地の文の段落で書く
・数字は英単語で綴る
    2,300 → two thousand three hundred
    15%   → fifteen percent
    $3.2 billion → three point two billion dollars
  ただし西暦は自然な読みにする（1995 → nineteen ninety-five、2026 → twenty twenty-six）
・略語は初出時にフルスペルを先に言う
    （例: the World Health Organization, or W.H.O.）
・1段落は3〜5文。段落間は空行を1行あける
・対話形式にしない。ニュースキャスター1人が読む原稿として書く
・日本語の人名・地名は、英語話者が読める綴りにする
・本文に日本語を一切混ぜない（日本語は最後の指定箇所にだけ書く）

━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 4. パート構成
━━━━━━━━━━━━━━━━━━━━━━━━━━
レベルごとに Part 1 / Part 2 / Part 3 の3つに分ける。

  Part 1  World News   : 世界のニュース2本
  Part 2  Japan News   : 日本のニュース2本
  Part 3  Focus & Drill: Part 1 か Part 2 から1本を選び、背景・影響・
                         賛否の両論を掘り下げた解説文（そのレベルの
                         総語数の3割程度）
                         そのあとに Key Vocabulary を8語
                         （英単語 / 品詞 / 英語での短い定義 / 例文1文。
                          すべて英語。読み上げてよい形で書く）
                         そのあとに Comprehension Questions を5問
                         （英語の質問文のみ。選択肢は作らない）

━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 5. 出力の形
━━━━━━━━━━━━━━━━━━━━━━━━━━
各パートを次の形で出力する。私は「▼ここから」〜「▲ここまで」を
まるごとコピーして読み上げAIに貼るので、その範囲に日本語や
余計な説明を絶対に入れないこと。

════════════ Part 1  World News ════════════
▼ここから
Read the following English text aloud at about 150 words per minute, in a
calm, neutral news-anchor voice. Read it straight through. Do not translate,
summarize, or add any comment.

（ここに英文本文。記号なし・段落のみ）
▲ここまで
Word count: ◯◯◯ words ／ 目安 ◯分◯◯秒

読み上げ速度は 準1級=150 / 2級=130 / 3級=110 wpm を指定する。

━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 6. 最後に日本語パート
━━━━━━━━━━━━━━━━━━━━━━━━━━
全パートのあとに、次の形で日本語のまとめを付ける。ここだけ日本語で書く。

════════════ 日本語まとめ（聞き終わってから） ════════════

■ 今日のニュース
・（4本それぞれの要約を2〜3行で）

■ 出典
・（媒体名）

■ Key Vocabulary
・（8語それぞれ「単語 ： 和訳 ： 英検での出題イメージ」）

■ 設問の解答
・（Comprehension Questions の解答）

■ 今日のシャドーイングのコツ
（1〜2行。発音・リエゾン・イントネーションのどれか1点に絞る）

━━━━━━━━━━━━━━━━━━━━━━━━━━
■ 7. 自己チェック（出力前に必ず実行）
━━━━━━━━━━━━━━━━━━━━━━━━━━
出力する前に次を1つずつ確認すること。チェック結果自体は出力しない。

 1. 本文に記号・絵文字・Markdownが残っていないか
 2. 本文中の算用数字がすべて英単語に直っているか
 3. 各レベルの総語数が指定レンジに収まっているか
 4. 3級を書いた場合、中学範囲外の語・文法が混ざっていないか
 5. 複数レベルを書いた場合、事実関係に食い違いがないか
 6. 「▼ここから」〜「▲ここまで」の中に日本語が混ざっていないか
 7. Word count の数値が実際の語数と合っているか

それでは {{DATE}} 版を作成してください。
```

## ChatGPT 側での読み上げのコツ

- 生成された Part を1つずつ ChatGPT に貼り、音声モードで再生する
- 1回目はスクリプトを見ずに聞く → 2回目でスクリプトを見ながら聞く →
  3回目でシャドーイング、の3周が10分に収まる分量にしてあります
- 聞き取れなかった箇所は `Read the third paragraph again, more slowly.` で部分再生できます
- 日本語まとめは**聞き終わってから**見てください（先に見るとネタバレになります）

## 長さを変えたいとき

「■ 2」の総語数を書き換えるだけです。15分やりたいなら準1級を 2000〜2200語に、
5分で済ませたいなら 700〜800語にしてください。Word count の表示も自動で追従します。
