# 03. バージョンアップ計画(ロードマップ)

## 全体像

| フェーズ | 期間目安 | ゴール |
| --- | --- | --- |
| Phase 0 準備 | 〜2週間 | 事実確認・素材集め・ドメインとホスティング決定 |
| Phase 1 MVP | 2〜4週間 | このスターターを完成させて公開。旧サイトから誘導 |
| Phase 2 運用強化 | 公開後1〜3か月 | スタッフがスマホで更新できる。天気・祝日・天文現象の自動化 |
| Phase 3 拡張 | 3か月〜 | 予約・多言語・願い星オンライン・寄附など収益/集客の柱 |

---

## Phase 0: 準備

- [ ] 施設ヒアリング(`docs/04-content-inventory.md` の「要確認」を全部埋める)
- [ ] 写真素材: 75cm望遠鏡、ドーム外観(昼/夜)、星と森の科学館の展示、山頂からの眺望、星空、願い星ポスト。**使用許諾**も確認
- [ ] ロゴの有無(なければ簡易ロゴを作るか文字ロゴで運用)
- [ ] 独自ドメイン取得(候補を複数出して空き確認。所有者は町/指定管理者名義に)
- [ ] ホスティング決定(推奨: Cloudflare Pages — 無料・高速・独自ドメイン HTTPS 自動)
- [ ] 更新担当者と更新ルール(誰が・いつ「今夜の開催可否」を更新するか)

## Phase 1: MVP 公開

- [ ] 要確認情報の確定 → `facility.ts` を `verified: true` に
- [ ] サンプル記事を実際の記事に差し替え(`【サンプル】` が残っていると公開ビルドが失敗する)
- [ ] 写真の組み込み(Astro の `<Image>` で WebP 自動変換)、OGP 画像(1200×630)
- [ ] お問い合わせフォームの送信先決定(Formspree / Google フォーム等)
- [ ] アクセス解析(Cloudflare Web Analytics なら Cookie 不要)
- [ ] 公開: `PUBLIC_ALLOW_INDEX=true`、`SITE_URL` 設定、`public/robots.txt` を公開用に
- [ ] **旧サイトからの誘導**: sun-net.jp 側のトップに「新しいサイトはこちら」+ meta refresh を置いてもらう
- [ ] Google Search Console・Bing Webmaster 登録、Googleビジネスプロフィールの URL 更新
- [ ] 観光サイト各所(しまね観光ナビ、津和野観光、JRおでかけネット等)に新 URL と正しい情報で修正依頼

## Phase 2: 運用強化(スタッフが自分で回せる仕組み)

| 機能 | 実装案 | 効果 |
| --- | --- | --- |
| **CMS** | Keystatic / Decap CMS(Git ベース・無料)か microCMS(SaaS) | イベント・お知らせをスタッフがブラウザから投稿 |
| **今夜の開催可否をスマホで更新** | ① CMS の単一エントリ ② Google スプレッドシートを公開 JSON 化してクライアントで読む ③ Cloudflare Workers + KV | 電話問い合わせの削減。**一番効果が大きい** |
| **祝日の自動判定** | `@holiday-jp/holiday_jp` 等で祝日データを持ち、「祝日の場合は翌平日休館」を自動化 | `calendar-overrides.json` の手入力が減る |
| **天気・雲量の表示** | Open-Meteo API(無料・キー不要)で今夜の雲量予報を表示 | 天文ファンの来館判断に直結 |
| **天文現象カレンダー** | 国立天文台 暦計算室のデータで流星群・月齢・惑星の見ごろ | イベント企画・SNS 発信のネタ元 |
| **毎日の自動再ビルド** | GitHub Actions の cron で毎朝ビルド | 「これからのイベント」の鮮度維持 |
| **SNS 開設と連携** | Instagram / X / LINE 公式アカウント | 当日の開催可否・天文現象の速報 |
| **月齢計算の高精度化** | 天文計算ライブラリ(astronomy-engine 等)に置換 | 月の出入り時刻も出せる |

## Phase 3: 拡張(集客・収益・地域連携)

| 機能 | 内容 | 留意点 |
| --- | --- | --- |
| **予約システム** | 特別観望会・団体見学の Web 予約(定員管理) | まずは STORES 予約 / Googleフォーム等の外部サービスで十分 |
| **願い星★宅配便 オンライン** | Web で願いごとを投稿 → 天文台で掲示・七夕に紹介。遠方の人との接点に | 投稿内容の確認(モデレーション)と個人情報の扱い |
| **多言語化** | 英語ページは2026-10に削除(日本語のみの方針)。必要になったら改めて検討 | 機械翻訳のままにしない |
| **教育プログラム** | 学校団体向けプログラム・事前学習教材 PDF・オンライン出前授業 | 学習指導要領(小4「月と星」、小6「月と太陽」、中3「地球と宇宙」)と対応づける |
| **ギャラリー** | 75cm望遠鏡で撮った天体写真、来館者の星空写真 | 撮影者の許諾 |
| **寄附・ふるさと納税の導線** | 望遠鏡の保守・オーバーホール等の目的別寄附、個人版/企業版ふるさと納税の案内 | 町の担当課と制度設計を確認 |
| **観光連携** | 津和野の宿泊・飲食と組み合わせた「星空ツーリズム」モデルコース | 夜間の移動手段(タクシー・送迎)が鍵 |
| **ライブ配信** | 天文現象(日食・月食・彗星)の望遠鏡映像配信 | 通信環境の確認 |

## KPI(公開3か月後に測る)

- 「日原天文台」の検索で公式サイトが1位
- 当日の開催可否に関する電話問い合わせ件数(公開前比で減少)
- 「今夜の開催可否」の更新率(開館日に対する更新日の割合 90% 以上)
- スマホの直帰率、ご利用案内・アクセスページの閲覧数
- 来館者アンケートの「何で知ったか」に Web/SNS が占める割合
