# 01. 現行サイト分析

調査日: 2026-10-18

## 0. 調査方法と限界

- 現行の公式サイト `http://www.sun-net.jp/~polaris/top.htm` は、調査環境のネットワーク制限のため**直接取得できなかった**。
- そのため、以下は **検索エンジンのインデックスと第三者サイト(観光サイト・報道・Wikipedia 等)の掲載情報** にもとづく分析である。
- 「推定」と書いた項目は、Cursor 側で実際にサイトを開いて確認すること(→ 末尾の「Cursor で最初にやる確認」)。

## 2. 課題の整理

### A. 信頼性・技術面

1. **独自ドメインがない** — URL がプロバイダ契約に依存している。契約変更・サービス終了でサイトごと消え、被リンクや検索評価もすべて失うおそれがある。「日原天文台の公式」と判別しにくい。
2. **HTTPS 非対応(推定)** — Chrome 等で「保護されていない通信」と出る。検索評価でも不利。
3. **2000年代前半型のつくり(推定)** — `.htm` 拡張子・`~user` ディレクトリは手作りの静的 HTML の特徴。スマホ対応(レスポンシブ)・構造化データ・OGP がない可能性が高い。

### B. 情報の正確さ・一貫性

公式サイトが「正」として参照されていないため、第三者サイトの情報が食い違っている:

| 項目 | 食い違いの内容 |
| --- | --- |
| 夜間の子ども料金 | 400円/200円 |
| 住所 | 枕瀬806-1/枕瀬801-8 |
| 開館時間 | 「見学13:30〜17:00+観測19:00〜22:00」/「13:30〜22:00」 |
| 日原駅からの所要時間 | タクシー5分/車15分 |
| メール | sun-net.jp/Gmail |
| 名称表記 | 日原天文台/にちはら天文台 |

→ 新サイトでは **構造化データ(schema.org)で公式情報を機械可読にし**、観光サイト各所へ修正依頼を出すまでをセットで行う。

### C. 来館者にとっての使いやすさ

1. **「今夜やっている?」がわからない** — 天文台で一番多い問い合わせは当日の開催可否のはずだが、Web で伝える手段がなく電話頼み(推定)。
2. **重要なお知らせが埋もれる** — 2021年9月〜2025年4月の道路通行止めのような重大情報が、アクセスページの中に書かれている。トップで目立たせる仕組みがない(推定)。
3. **スマホで見づらい(推定)** — 来館者の多くは観光中・移動中にスマホで調べる。
4. **英語情報がない** — 外国人向けは島根県観光サイトの英語ページのみ。

### D. 集客・発信

1. 「日原天文台」で検索しても公式サイトが上位に来ず、観光ポータルが並ぶ。
2. SNS がないため、天文現象(流星群・日食・彗星など)にあわせた発信ができていない。
3. 「日本初の公開天文台」「すばるにつながる75cm望遠鏡」「願い星★宅配便」と、強い物語があるのに活かしきれていない。

## 3. 強み(新サイトで前面に出すもの)

- **日本初の公開天文台**(1985年、ハレー彗星接近の年に開設)
- **口径75cm反射望遠鏡**(経緯台・ナスミス焦点。すばる望遠鏡につながる技術 ※表現は要確認)
- **昼間も星が見える**(太陽・昼間の明るい星)— 夜に来られない観光客や家族連れに訴求できる
- **星と森の科学館**(1994年開館、宇宙と地球環境、重力体験)
- **願い星★宅配便**(階段横のポスト)— SNS 映え・オンライン化の余地
- **ロケーション** — 津和野川と高津川の合流点を見下ろす枕瀬山の山頂。津和野観光と組み合わせやすい
- **人材** — 地域おこし協力隊で天文台ガイドを募集(令和7年度)。発信の担い手ができるタイミング

## 5. Cursor で最初にやる確認

1. 実ブラウザで `http://www.sun-net.jp/~polaris/top.htm` を開き、全ページを洗い出す(リンクをたどってページ一覧と URL を `docs/04-content-inventory.md` に追記)。
2. HTTPS で開けるか、スマホ表示、最終更新日、画像の有無と解像度を確認。
3. 旧サイトにしかない情報(歴史、望遠鏡の詳細、写真、過去イベント)を抜き出して新サイトの原稿にする。
4. Wayback Machine(web.archive.org)で過去の版を確認し、消えた有用コンテンツがないか見る。
