# 02. 新サイト要件定義(Phase 1 / MVP)

## 目的

1. **「今日・今夜行けるか」が10秒でわかる**サイトにする(電話問い合わせを減らす)
2. **公式情報の「正」**になる(第三者サイトの誤情報を正せる状態に)
3. 「日本初の公開天文台」の**物語で来館動機をつくる**
4. スタッフが**専門知識なしで更新できる**(Phase 2 で CMS 化)

## 想定ユーザー

| ペルソナ | 状況 | 知りたいこと |
| --- | --- | --- |
| 津和野観光の家族連れ | 観光中にスマホで検索 | 今日開いてる?昼でも楽しめる?子ども料金は?何分で着く? |
| 天文ファン | 遠方から天文現象にあわせて来訪 | 今夜晴れる?観望会やる?望遠鏡のスペック、撮影できる? |
| 学校・団体の引率者 | 校外学習の下調べ | 団体受入れ、所要時間、バス駐車、問い合わせ先 |
| 地元の人 | 季節のイベント情報 | 次のイベントはいつ? |
| 外国人旅行者 | 英語で検索 | 基本情報(時間・料金・行き方) |
| メディア・行政 | 取材・視察 | 施設概要、沿革、写真素材、連絡先 |

## サイトマップ

```
/                 トップ(今日の開館状況・今夜の観望会・月齢/見どころ/イベント/お知らせ/アクセス)
/visit/           ご利用案内(時間・料金・休館日・観望会の注意)
/facility/        施設紹介(75cm望遠鏡/星と森の科学館/天文資料館/願い星★宅配便/あゆみ)
/events/          イベント一覧(開催予定・過去)
/events/{slug}/   イベント詳細(Event 構造化データ付き)
/news/            お知らせ一覧
/news/{slug}/     お知らせ詳細
/access/          アクセス(道路状況・地図・電車・車)
/contact/         お問い合わせ(電話・メール・フォーム)

```

## 非機能要件

- **表示速度**: JS は最小限(Astro の静的出力)。Lighthouse Performance 90 以上を目標
- **スマホ優先**: 幅 375px で横スクロールなし、タップ領域 44px 以上
- **アクセシビリティ**: WCAG 2.1 AA(コントラスト、キーボード操作、スキップリンク、`lang` 属性)
- **運用コスト**: ホスティングは無料枠(Cloudflare Pages / Netlify / GitHub Pages)で運用可能に
- **セキュリティ**: 静的サイトのためサーバー攻撃面なし。フォームは外部サービスを利用
- **独自ドメイン + HTTPS**: 必須(例: `nichihara-obs.jp` 等。取得可否は未確認)

## 技術スタック

| 項目 | 採用 | 理由 |
| --- | --- | --- |
| フレームワーク | Astro 7(静的出力) | 速い・JS が少ない・Markdown で記事管理・CMS 連携が容易 |
| 言語 | TypeScript(strict) | Cursor の補完が効き、データの型崩れを防げる |
| スタイル | 素の CSS + CSS 変数(`global.css`) | 依存を増やさない。Tailwind 導入は任意 |
| テスト | `node --test`(ロジック)+ `astro check`(型) | 依存ゼロ |
| Node | 22.22 以上(`.nvmrc`) | Astro 7 の要件 |
