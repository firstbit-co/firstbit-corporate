# 理念とビジョン

## 理念（Philosophy）

> 本質的な価値を見極め、最新の情報で未来につながる豊かさを創造する。

社名である「First bit」は、情報の最小単位であり、データにおける「最初の一文字」を意味する。代表自身が高校から大学院まで一貫して「情報」を探求し、教員免許も有する背景から、現代社会における「情報の大切さ」を深く認識している。「常に最新の情報を、どこよりも早く届け、顧客の明るく豊かな将来に貢献したい」——これが原点。

企業経営、資産形成、事業承継、福利厚生、観光事業などを通じて、顧客一人ひとりの人生と事業に寄り添い、長期的な価値の創出を支援する。単なるサービスの提供ではなく、最新の知見をもとに顧客の未来にとって本当に必要な選択肢を見極め、安心と豊かさにつながる仕組みをつくることを大切にしている。

経営者、企業、地域、そしてそこで働く人々にとって、より良い未来を切り拓くための「最初の一手（First bit）」となる存在を目指す。

## ビジョン（Vision）

> 最新の情報・確かな知見・上質なサービスで、企業価値と人生の豊かさを高める。

財務コンサルティング、M&A・事業承継、金融・投資教育、福利厚生サービス、観光事業を通じて、企業と個人の持続的な成長を支援する。会員制の福利厚生サービスでは安心して働き続けられる環境づくりをサポートし、宿泊・観光事業では地域資源を活かした特別な体験価値を提供する。

情報・金融・経営・教育・ウェルビーイング・観光の領域を掛け合わせることで、従来の枠にとらわれない新しい価値を創出し、企業価値の向上と地域価値の発展に貢献する。

## 大切にしている価値観

| 価値観 | 内容 |
| --- | --- |
| 信頼 | 顧客の立場に立ち、長期的な視点で誠実な提案を行う |
| 情報 | 常に新しい情報を学び、正しく見極め、価値ある形で提供する |
| 本質 | 目先の利益だけではなく、本当に価値のある選択肢を見極める |
| 上質 | 一人ひとりに寄り添い、細部まで配慮した質の高いサービスを追求する |
| 継承 | 事業、資産、想い、地域資源を次世代へつなぐ支援を行う |
| 創造 | 金融・経営・福利厚生・観光を組み合わせ、新しい価値を生み出す |
