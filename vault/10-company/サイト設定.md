# サイト設定

`index.html` の `<head>`（タイトル・ディスクリプション・OGP）、お問い合わせ文、フッターの著作権表示と PDF リンクの出どころ。
ここを直して `npm run build` を実行すると `index.html` に反映される。

検索対策で社名の表記ゆれ（Firstbit / First bit / firstbit / first bit / ファーストビット）を
`keywords` と各所の別名に入れている。減らすと検索流入に影響するため、変更は慎重に。
